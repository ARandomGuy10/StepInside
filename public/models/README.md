# Furniture models

Put glTF binary files here, named after the `model` field of a furniture
piece in the scene file. A piece with `"model": "sofa"` loads
`/models/sofa.glb`. The model is scaled to the piece's `size` and stood
on the floor. When no file exists, the app draws a plain box of that size.

Only add models with a CC0 licence, and note the source of each one below.
